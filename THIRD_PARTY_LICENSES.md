## 3. External services (not redistributed)

The behavior-tree generation agent calls hosted large-language-model APIs. These
are services accessed over the network at runtime; no provider code or model
weights are redistributed in this repository. Use of each is subject to the
provider's own terms of service:

- **OpenAI API** (GPT models) — via `langchain-openai`
- **Anthropic API** (Claude models) — via `langchain-anthropic`
- **Google Gemini API** — via `langchain-google-genai`

API keys are supplied by the user through a local `.env` file and are never
committed to the repository.
